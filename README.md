# The Opulent Beauty Bar — Luxury Salon Pitch Website

An ultra-luxurious, responsive one-page website prototype designed specifically to pitch to **The Opulent Beauty Bar** (`@theopulent.beautybar`), Latif Plaza, Block 6, Gulshan-e-Iqbal, Karachi.

---

## 🌟 Live Demo Preview
Once GitHub Pages is enabled:
👉 **`https://khawarlfusa-coder.github.io/opulent-/`**

---

## 💎 Features & Highlights

- **Bespoke Luxury Design**: Obsidian, Warm Charcoal, and Champagne Gold color palette with editorial serif typography.
- **Smart WhatsApp Booking Engine**: Directly formatted for front desk WhatsApp (`+92 328 2651011`). Clients pick treatment, date, and preferred time slot with instant preview.
- **Service Menu with Dynamic Filtering**: Categorized by Hair & Color, Nail Lounge, Skin & Medi-Facials, Bridal & Glam, and Waxing.
- **The Opulent Standards**: Showcasing hospital-grade sterilization and imported European products (Olaplex, L'Oréal, Casmara, CND).
- **Client Lookbook**: Filterable portfolio gallery.
- **Gulshan-e-Iqbal Location Integration**: Landline (`021-34182244`), timings (12:00 PM – 9:00 PM daily), and Google Maps integration.
- **Client Pitch Strategy**: Included in `PITCH_STRATEGY.md` with domain recommendations (`opulentbeautybar.pk`, `theopulentbeautybar.com`) and negotiation talking points.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic tags, OpenGraph social sharing meta, JSON-LD `BeautySalon` schema.
- **CSS3**: Custom properties, glassmorphism, responsive grid & flexbox, smooth micro-animations.
- **Vanilla JavaScript**: Zero external dependencies for maximum speed on mobile devices.
- **Icons & Typography**: Google Fonts (*Playfair Display*, *Cormorant Garamond*, *Plus Jakarta Sans*) + FontAwesome 6.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/khawarlfusa-coder/opulent-.git

# Navigate into directory
cd opulent-

# Open directly or run with node
node serve.js
```
Then open `http://localhost:8000` in your web browser.
